# Objetivo

Criar uma plataforma web que facilite o planejamento e o acompanhamento da graduação em Engenharia de Computação da UFERSA, reunindo em uma interface intuitiva o roadmap do curso e informações organizadas sobre cada disciplina.

# Tecnologias Utilizadas

| Camada           | Tecnologia                               |
| ---------------- | ---------------------------------------- |
| Linguagem        | Python 3.13+                             |
| Framework        | Django 5                                 |
| Banco            | SQLite → PostgreSQL                      |
| ORM              | Django ORM                               |
| Templates        | Django Templates                         |
| Frontend         | HTML5 + CSS + JavaScript                 |
| Estilo           | Tailwind CSS                             |
| Ícones           | Lucide                                   |
| Imagens          | Pillow                                   |
| Formulários      | django-crispy-forms (opcional)           |
| Editor Rich Text | django-ckeditor (opcional)               |
| Versionamento    | Git + GitHub                             |
| Deploy           | Railway/Render + PostgreSQL + WhiteNoise |
